How to make new posts (2026 version with GitHub custom action build)
1. Open "C:\Users\USERNAME\Dropbox\elmamakindergarten\blog\_posts", copy post and change content

TEST LOCAL BUILD
2.1 (if new install): cmd -> cd(C:\Users\USERNAME\Dropbox\elmamakindergarten) -> 'bundle install'
2.2 cmd -> cd(C:\Users\USERNAME\Dropbox\elmamakindergarten) -> 'bundle exec jekyll serve'
3. open browser, enter "http://localhost:4000/"

PUSH TO REMOTE
4. Open github desktop app, commit and push changes
5. Open github (personal account is ok), go to elmama repo, check under 'actions' if site was built correctly.
